# BetterGI Android 使用说明

1. 安装 APK，并允许悬浮窗权限。
2. 在系统设置里开启 **更好的原神** 的无障碍服务。
3. 打开 **更好的原神**，确认悬浮球出现。
4. 使用 **更好的原神** 启动原神。
5. 点击悬浮球，开启 **屏幕共享**。
6. 屏幕共享成功后，开启 **自动剧情**。

## 常见问题

- **显示“原神未打开”**：关闭再重新开启无障碍服务。
- **自动剧情是灰色**：确认原神已被识别，并且屏幕共享已开启。
- **后台失效**：把 BetterGI Pocket 的电池策略设为“不限制后台运行”。
- **录屏冲突**：部分手机不能同时使用系统录屏和 BetterGI 的屏幕共享。
